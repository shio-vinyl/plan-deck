# 地图类型目录 v0

规划汇报里的地图是主要证据，也是“规划味”的主要来源。本目录列出规划汇报里常见的地图类型，并划定与 gis 系列的分工。

目录是开放的参考，不是必选项。按传统规划内容命名的几类（如三区三线、双评价）只是“同范围多联图”“专题叠加”等通用形式的常见实例，可以随项目换成别的内容。

## 分工原则

- **gis-kit**：数据准备与分析，产出可回读的文件（范围、分类统计、覆盖分析、指标表数据）。
- **gis-composer**：按项目视觉系统出图，产出 PNG 和元数据（图例项、比例尺、指北针、安全区）。
- **plan-deck**：定义地图槽位的规格（尺寸、比例、图例放图内还是页面上），把图和元数据排进页面；图例、指标表、标注文字尽量做成**可编辑的 pptx 元素**，而不是烧进图片。
- 示意性的图（空间结构的轴、带、心）不是严格的 GIS 产物：底图由 gis-composer 出，结构符号可以由 plan-deck 用可编辑形状叠加。

具体接口见 `architecture.md` 的“地图衔接”。gis-kit、gis-composer 的现有能力以各自仓库为准，下表的分工是规划时的设想，用到某类图时按两边的实际能力核对。

## 成组出图

规划汇报里地图很少单张出现，更多是成组：同范围三联（双评价、现状三联图）、同底图连续页（二十多页只换专题层）、方案对页（高 / 低方案）。因此地图请求应支持**同一组共享范围、画幅、比例尺和底图**，plan-deck 按组排版，保证翻页时图不跳动。

## 鲜艳实用汇报的地图

**什么时候用：** 不怎么讲究美观、更看重投影上一眼看清的实用汇报。讲究美感的稿子、正式图集、论文配图不用这一套，按项目视觉系统另定。默认不用，要明确选。

**出图：** gis-composer 的项目主题继承内置主题 `vivid-report`（`project init --theme vivid-report`，或项目主题写 `"extends": "vivid-report"`），`style.json` 的 `mapTheme` 指向这个项目主题，页面配色和图面同源。它定的是：

- 底图只留中性灰白，内容用高饱和色；
- 类别色依次取红 `#FF0000`、蓝 `#0064FF`、橙 `#FF6A00`、绿 `#00B050`，第五类才用紫 `#7A00FF`；黑色留给设施，站点用国空制图规范的符号（gis-composer 符号库）；
- 注记纯黑、白色不透明光晕；
- 要强调的范围（核心区、研究范围）画红色虚线，约 1.5 磅，尖角平头，不填色；
- 只作背景的范围（地铁站 500 米、800 米范围，服务半径）用低饱和的沙色块（近 `#E3CB9E`、远 `#F3E8D2`），不画边线；黑色实线、虚线或红色系都会抢红点；
- 片区线是实线、尖角，不加白边。

**页面：** 名称做成可编辑的注记方框，图例压成一列放进地图角上的空白处，左栏补满原来图例的位置：

```python
m = p.map(maps.map('m3-strategy'), mx, y0, mw, y1 - y0)
p.map_label(m, '西岸 12 街坊', at=(3.1, 4.6), box_at=(4.2, 3.4), r=0.16)   # 相对地图左上角的 cm；r 是点的半径
p.inset_legend(maps.map('m3-strategy'), m)                                 # 默认左下角；corner='top-right' 等
```

- `map_label`：白底黑框直角方框，字纯黑加粗、字号 `mapText.labelPt`；细黑引线从方框最近一边的中点指到点的边缘；方框不出地图的边。方框版胜过只有引线的文字版。
- `inset_legend`：白底细边框，顶上“图例”，不出分组标题；点画同色圆点，面（含背景范围）画同色小方块，线画一段线（`legend.json` 有 `dasharray` 就是虚线），符号库的符号照 svg 画；尺寸行、`context` 行默认不画；地图清单写 `legend: {visible: false}`，图例不进 PNG。
- 两个组件新加的形状都不带阴影（运行时去掉了主题样式引用），出样张前照样跑 `plan-deck inspect`。

**规则（主题管不到，出图和排页时自己守）：**

- 一张图别叠太多类、太多图例项；拆成几张同范围的图能讲清楚就拆。`inset_legend` 超过 6 行时记警告。
- 黄色不用在点上：白底上对比度约 1.1，看不见。黄色只给面用。`inset_legend` 遇到黄色的点类记警告。
- 含义优先于颜色顺序：用地分类色、三区三线（永农黄、生态红线绿、开发边界红）等行业已有配色照用；同一含义全册同色，拆开的几张图也一样。
- 强调靠红色虚线和高饱和的点，不靠大块浅色面；浅色块只给背景范围。

## 画幅和配色的常见做法

- 图文二分页里主图多靠右，宽度为页宽的 40%–66%，左栏放文字；同一专项连续几页，主图的位置和尺寸完全一致。
- 2019 年以后的总规、村规划汇报已按三调和《国土空间调查、规划、用途管制用地用海分类指南》的分类出图。

每类地图的默认画幅、图例摆放，以及用地分类配色取哪个版本，还没有定，见 Issue #11。
