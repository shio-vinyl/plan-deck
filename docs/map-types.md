# 地图类型目录 v0

规划汇报里的地图是主要证据，也是“规划味”的主要来源。本目录列出规划汇报里常见的地图类型，并划定与 gis 系列的分工。

目录是开放的参考，不是必选项。按传统规划内容命名的几类（如三区三线、双评价）只是“同范围多联图”“专题叠加”等通用形式的常见实例，可以随项目换成别的内容。

## 分工原则

- **gis-kit**：数据准备与分析，产出可回读的文件（范围、分类统计、覆盖分析、指标表数据）。
- **gis-composer**：按项目视觉系统出图，产出 PNG 和元数据（图例项、比例尺、指北针、安全区）。
- **plan-deck**：定义地图槽位的规格（尺寸、比例、图例放图内还是页面上），把图和元数据排进页面；图例、指标表、标注文字尽量做成**可编辑的 pptx 元素**，而不是烧进图片。
- 示意性的图（空间结构的轴、带、心）不是严格的 GIS 产物：底图由 gis-composer 出，结构符号可以由 plan-deck 用可编辑形状叠加。

具体接口见 `architecture.md` 的“地图衔接”。gis-kit、gis-composer 的现有能力以各自仓库为准，下表的分工是规划时的设想，用到某类图时按两边的实际能力核对。

## 成组出图

规划汇报里地图很少单张出现，更多是成组：同范围三联（双评价、现状三联图）、同底图连续页（二十多页只换专题层）、方案对页（高 / 低方案）。因此地图请求应支持**同一组共享范围、画幅、比例尺和底图**，plan-deck 按组排版，保证翻页时图不跳动。

## 画幅和配色的常见做法

- 图文二分页里主图多靠右，宽度为页宽的 40%–66%，左栏放文字；同一专项连续几页，主图的位置和尺寸完全一致。
- 2019 年以后的总规、村规划汇报已按三调和《国土空间调查、规划、用途管制用地用海分类指南》的分类出图。

每类地图的默认画幅、图例摆放，以及用地分类配色取哪个版本，还没有定，见 Issue #6。
